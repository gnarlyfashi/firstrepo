## Visualization
Graph artifacts generated by your pipeline can be turned into interactive or static diagrams.

```python
from b_pkg.models import Concept, Edge, GraphArtifact
from b_pkg.viz import render_graphviz, render_pyvis

artifact = GraphArtifact(
    concepts=[
        Concept(id="c1", label="Variables", bloom_level="remember", type="concept", confidence=0.9),
        Concept(id="c2", label="Loops", bloom_level="understand", type="concept", confidence=0.7),
    ],
    edges=[Edge(source="c1", target="c2", label="prerequisite", confidence=0.85)],
)

render_pyvis(artifact, "graph.html")  # interactive HTML
render_graphviz(artifact, "graph.svg")  # static Graphviz output
```

If you prefer a UI, run the minimal Streamlit helper:

```bash
streamlit run examples/visualize_artifact.py
```

Upload a serialized `GraphArtifact` JSON file to explore the graph interactively in your browser.
